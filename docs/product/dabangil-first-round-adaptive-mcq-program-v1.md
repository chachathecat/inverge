# 답안길 감정평가사 1차 Adaptive MCQ 프로그램 v1

1차는 2차의 부속 문제은행이 아니며 취소되지 않는다. 기존 공통 MCQ kernel과
과목 adapter를 재사용하고, 선택 → 설명 → 직접 재풀이 → 다음 날 → 다른 문제 →
제한시간 확인을 같은 개인 학습 증거·오늘 계획으로 연결한다.

## 범위

- 민법
- 경제학원론
- 부동산학원론
- 감정평가 관계 법규
- 회계학

영어는 앱이 채점하는 여섯 번째 과목이 아니라 외부 공인성적 요건으로만 표시한다.
40문항/120분, 80문항/200분 묶음과 과목별 러너는 실제 문항·권리·검증이 준비된
범위에서만 열린다.

맞힌 클릭, 해설 열람, 힌트 사용 또는 같은 문항 즉시 재시도만으로 `현재 안정`을
만들지 않는다. 정답은 공식·검증된 key가 우선하며 모델 출력은 정답 권위가
아니다. 우연히 맞힌 답, 강한 도움 뒤 답, 출처가 불명확한 문항은 독립 전이
증거가 될 수 없다.

## 순서

강한 signed-in 2차 기술 trial 뒤, broad native나 다른 전문시험보다 먼저 다음을
이어간다.

`FIRST-P0 → FIRST-P1 → ULC-F1 → ULC-F2 → ULC-F3 → ULC-F4 → ULC-F5 → FIRST-P2 → FIRST-P3 → FIRST-P4`

`FIRST-P3`에서 1차와 2차는 같은 오늘 화면의 증거 기반 한 가지 행동으로 연결하되
각 과목·단계의 저장과 평가 의미를 섞지 않는다. 실제 콘텐츠 설치·승인·공개는
별도 권한이며 합성 fixture는 과목 완성을 뜻하지 않는다.
