# 답안길 감정평가사 2차 Web/PWA 제품 계약 v1

## 약속

> 답안을 올리면 가장 큰 감점 원인 하나를 찾아 오늘 고칠 문단이나 계산을 정합니다.

첫 화면에는 경쟁하는 주 행동을 두지 않는다. signed-in 학습자에게는 한 가지
행동의 `무엇`, `지금인 이유`, `예상 시간`, `끝난 뒤 다음 단계`를 보인다.

학습자 순서는 다음으로 고정한다.

`오늘 고치기 → 다음 날 혼자 해보기 → 일주일 뒤 다른 문제 → 제한시간 실전 확인 → 현재 안정`

## 핵심 흐름

`문제·답안·PDF/사진 → OCR 확인 → 온라인 자동검토 → 일반 피드백 → 가장 큰 감점 원인 → 쉬운 설명 → AI 학습용 기준안 → 직접 재작성·재계산 → 재검수 → 다음 날/일주일 뒤 일정`

실무의 수치·단위·부호·반올림은 결정론 검증이 우선한다. 이론은 목표 범위와
근거를, 법규는 정확한 출처·시행 버전·현행성을 갖춰야 한다. 모델 출력은 이를
덮어쓸 수 없다.

공식 채점, 공식 모범답안, 점수·합격 보장으로 표현하지 않는다. 기준안은 항상
`AI 학습용 기준안`이다. 모든 기준안은 출처 상태, 검증 상태와 불확실성을 함께
표시한다. 법규 출처, 계산 또는 미해결 합의 오류가 하나라도 차단 상태이면
기준안을 공개하지 않는다. 공개 전에는 서로 독립인 후보를 최소 3개 만들고,
과목별 검증, 별도 critic 검토, 합의·충돌 처리와 출처 anchor 결합을 거친다.
검증 보고서와 과목별 검사가 기존 reference-answer registry의 정확한 release
상태를 모두 충족하고 공개를 지지하는 evidence anchor가 있을 때만 연다. 최종
package 전체가 canonical validator를 통과하고, 실제 release decision과 학습
기준안 상태가 모두 `released`이며 공개 시각·비공식 답안 주의·권리 상태까지
유효해야 한다. 카드 열기나 읽기만으로 숙달·안정·독립 전이 증거를 만들지 않는다.

## 접근 경계

- signed-out: 미리 계산한 합성 데모만 제공한다. 개인 업로드, live OCR/AI,
  익명 지속 학습 계정은 없다.
- signed-in trial: 확인된 계정만 개인 입력을 처리한다. trial 시작은 가입이
  아니라 첫 usable review다. 실패한 OCR/provider/schema/storage는 사용량이
  아니다. 만료 뒤 읽기·내보내기·삭제는 유지한다.
- Production, 실제 학습자, 결제, 외부 공개는 이 계약으로 켜지지 않는다.

## 우선순위

Web/PWA의 3과목 직접 교정과 지연 확인이 critical path다. 캘린더·개념 모음,
20년 전체 corpus, 개인 문제 생성, 유료화, native companion은 별도 경로다.
Web/PWA가 안정되기 전 native 재작성은 하지 않는다.
