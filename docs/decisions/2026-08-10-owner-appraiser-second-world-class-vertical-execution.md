# Owner Decision — 감정평가사 2차 World-Class Vertical Execution Standard v1

## 1. 결정

V13은 계속 답안길의 유일한 active master plan이다.

새 V14 또는 V13.1 active master를 만들지 않는다. V13의 Trust, source,
rights, evidence, transfer, Full-Day와 privacy 원칙을 감정평가사 2차의
실제 learner-facing product로 번역하는 subordinate execution standard를
채택한다.

정식 이름:

> **Appraiser Second World-Class Vertical Execution Standard v1**

제품 약속:

> **내 답안의 가장 큰 감점 원인을 정확한 위치에서 찾아 직접 고치게 하고,
> 다음 날·다른 문제·제한시간 전체 답안에서 다시 틀리지 않는지 확인한 뒤,
> 그 증거로 오늘의 공부를 다시 정한다.**

## 4. 새로 고정하는 증거 무결성 계약

### 4.1 도움 제공 전 exposure 원자 기록

힌트, explanation, probe, worked step 또는 full solution의 어떤 byte도
반환하기 전에 trusted server가 append-only assistance/exposure event를
commit해야 한다.

- commit authority는 client, model, outer boolean 또는 request label이 아니다.
- commit 실패 시 help output은 정확히 0 byte이고 learning evidence도 0이다.
- 이미 노출된 attempt/item을 나중에 unseen으로 되돌릴 수 없다.
- 노출 뒤 독립 증거를 만들려면 별도의 distinct independent attempt가 필요하다.
- direct API, retry, multi-tab, cache와 prefetch도 같은 원칙을 우회하지 못한다.

### 4.2 D+1 frozen D0 configuration

D+1 evidence는 다음 frozen D0 binding과 정확히 일치해야 한다.

- problem revision
- source/effective version
- item release artifact
- model and prompt version
- rubric and validator version
- tutor, assistance, reveal and measurement policy
- Notebook/Ledger schema relevant to evidence
- Full-Day/scheduler policy when assignment or timing에 영향을 줌

하나라도 incompatible하면 기존 case는 stale이고 D0부터 다시 시작한다.
필요한 security repair는 evidence를 명시적으로 invalidate/restart할 수 있지만
incompatible evidence를 조용히 보존·결합할 수 없다.

### 4.3 실무 GIII 루틴

적용 가능한 실무 Golden vertical은 `casio_fx_9860giii`에 대해 다음을
모두 가진다.

- formula
- extracted values
- reset-safe hand-key sequence
- expected display
- unit/sign/rounding checks
- answer-sheet transfer
- reset 뒤 재현
- no-program-storage guardrail

계산기 루틴은 deterministic calculation/validation을 대체하지 않는다.

### 4.4 pyBKT 경계

pyBKT의 현재 disposition은 정확히 `benchmark_only`다.

- local synthetic benchmark는 허용된다.
- hidden shadow instrumentation은 자동 허용되지 않는다.
- shadow 전환에는 충분한 closed-schema skill-event data와 exact-scope O2
  measurement/consent gate가 모두 필요하다.
- pyBKT는 mastery, biggest gap, transfer, Today priority 또는 pass readiness
  authority가 아니다.

## 7. 불변식

- exact answer anchor 없이는 usable biggest gap이 아니다.
- evaluation completion은 successful learning evidence가 아니다.
- AI/guided/full-reveal/same-surface success는 independent transfer가 아니다.
- help output은 prior exposure commit 없이는 0 byte다.
- exposed work는 unseen으로 복귀할 수 없다.
- D+1은 frozen D0 configuration과 exact match해야 한다.
- D+7은 sealed verified non-same-surface item의 independent success가 필요하다.
- timed recurrence 없이는 gap closure가 아니다.
- 후속 qualifying failure는 closure를 reopen한다.
- 실무 deterministic conflict는 numeric release를 막는다.
- 법규 source/effective-version conflict는 verified release를 막는다.
- block completion은 mastery를 바꾸지 않는다.
- Today CoreOutcome은 0..3이다.
- Full-Day availableMinutes는 trusted-server integer 30..720이며
  ExecutionBlock은 그 안에서 0..N이다.
- engagement, streak, time-in-app는 learning priority를 결정하지 않는다.
- raw learner body는 shared analytics, graph label, calibration body,
  cross-user cache 또는 training에 들어가지 않는다.
- private raw learner content는 consent 여부와 무관하게 model training input이
  될 수 없다.
- future training 후보는 consented pseudonymous non-reconstructive signal 또는
  promoted Cleared Content Bank material뿐이다.
- one canonical MasteryState authority를 유지한다.
