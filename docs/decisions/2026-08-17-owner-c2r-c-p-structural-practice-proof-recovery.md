# Owner Decision — C2R-C-P Structural Practice-Proof Recovery

## 1. Structural disposition

PR #755 remains closed, unmerged and read-only. Its free-form Korean regex and
denylist validator is not copied, reopened, amended, cherry-picked or used as
verification authority. Its rights-safe fixtures, forced-RLS persistence,
private-artifact boundary, CAS/idempotency, Owner-only access, API/UI episode,
runtime evidence and rollback design may be reconstructed only where they are
independent of that parser defect.

The three terminal manifestations—omitted validity denials, hidden numeric
claims inside wrapper families, and truncated double negation—have one root:
free-form text parsing cannot safely establish canonical Practice proof.
Verification is therefore moved to a closed server-validated commitment. The
learner promise remains complete and the verification standard becomes
stronger.

## 2. Canonical authority boundary

Typed learner text, OCR, PDF and voice transcription remain private evidence
for an independent attempt, candidate extraction, diagnosis, gap ranking,
scaffold selection and learner history. No free-form body, parser result,
token, number, sign, wording, wrapper or denylisted phrase can create `PASS`,
`verified`, mastery, stability or transfer.

Same-session Practice `verified` requires one exact
`PracticeCalculationClaimV2` created by the server from a learner-confirmed
closed input. Unknown or duplicate JSON fields fail before transition
planning. The server validates safe integers, enums, units, source revision,
anchor and anchor version, operand roles and order, operator, result, sign,
rounding, current bindings and the independent-attempt boundary. A model or
client cannot submit `verified`, `PASS`, mastery or transfer fields.

The claim binds gross income `120,000,000 KRW_PER_YEAR`, operating expense
`20,000,000 KRW_PER_YEAR`, ordered `SUBTRACT`, result
`100,000,000 KRW_PER_YEAR`, `POSITIVE`, and `HALF_UP` scale zero with
`required=false`. It permits `EXTRACTED_THEN_EDITED` or `MANUAL_STRUCTURED`;
no prefill is automatically confirmed. `learnerConfirmedAt` is generated by
the server. A canonical Korean sentence rendered from an accepted claim is
output only.

## 3. Complete learner episode

The independently deployable Practice vertical preserves:

1. editable capture and source-revision confirmation;
2. prediction before help;
3. independent free-form attempt;
4. learner self-diagnosis before server diagnosis;
5. one ranked gap and smallest eligible scaffold;
6. free-form reconstruction;
7. explicit structured calculation confirmation;
8. deterministic server verification; and
9. `verified`, `partial`, `blocked`, guided or deferred continuation without
   mastery, transfer, score or pass claims.

Ambiguous or unsupported extraction leaves fields empty. The initial runtime
uses manual structured confirmation and makes no completeness claim for a
parser. Theory and Law runtime remain absent and separately owned.

## 4. Privacy, persistence and concurrency

The exact claim and all learner bodies remain owner-private. Canonical session
metadata is bodyless; bodies are append-only private artifacts. Every stage
table uses forced RLS, direct authenticated table access is denied, service
transitions bind the authenticated user, and source/fixture/anchor/rubric/
policy/validator drift fails closed. Session mutation is record-version CAS;
stable command IDs serialize duplicate and concurrent retry, and the exact
transition result replays idempotently.

Exposure is persisted before help bytes are returned. Guided exposure creates
no independent credit. Revision replacement clears structured proof and makes
the previous result stale. The runtime uses only rights-safe Inverge-original
synthetic fixtures and never trains on, shares or sends learner bodies to a
provider.

## 5. Hostile and metamorphic proof

The deterministic Node matrix carries every relevant example from PRs
#745–#755: roles, units, operators, results, ASCII/Unicode signs, full-width
forms, whitespace, punctuation, ASCII/curly/Korean quotes, matched/unmatched/
nested wrappers, repeated contradictions, denials, single/double negation,
rounding forms, structured mutations, binding drift and replay.

Those variations are intentionally irrelevant to canonical proof: free-form
text alone never verifies. The exact structured commitment passes; malformed,
unknown, duplicate, forged, contradictory or mutated closed fields fail. No
same-session outcome creates mastery, stability or transfer.

## 6. Delivery and resulting authority

The frozen 49-path manifest is exact in
`config/dabangil-c2r-c-p-structural-practice-proof-v2.json`. This candidate
changes no dependency or lockfile. It is default-off and Owner-only, applies
no remote migration, and authorizes no Production, provider, external user,
payment, public release, secret or destructive operation.

Merge requires all pinned GitHub-native checks on the exact head, the dedicated
disposable PostgreSQL and browser-to-Next runtime proof, resolved corrected
threads, a fresh `0/0/0` review, and expected-head-pinned squash merge. After
live validation, exactly one `MergeCoverageReceiptV1` index is published to
#717, implementation Issue #727 closes, #703/#704/#705/#706/#714/#717 remain
open as required, and the selector advances to
`C2R-C-T / #703 / authorized_unstarted`.

Rollback is non-destructive: keep
`WCV_C2R_C_P_PRACTICE_ENABLED=false`, remove the Owner-only route in a later
focused PR if needed, and preserve forward-only migration history and private
records. Practice rollback never requires reverting future Theory or Law.
