## 7. Adversarial source assertions

Focused tests must reject or detect:

- no exact anchor but usable biggest gap
- evaluation completion used as positive evidence
- help bytes returned without committed exposure
- generated full solution released without exact released S215 status, caveat,
  disclosures or zero blocking blocker/uncertainty state
- generated solution or disclosure bound to a near-match gate, question, S214
  pipeline, S207 package, source anchor or verification/evidence anchor
- historical released S215 or cached/embedded released S207 state used after the
  exact current canonical S207 package is no longer released, has an open blocking
  blocker, has unresolved blocking uncertainty or disables either downstream-use flag
- current S207 lookup missing, duplicate, ambiguous, invalid, foreign, stale or
  drifted before the first generated byte, or a prior successful check reused
- current S207 blocker/uncertainty entries with missing fields, unknown enums or
  non-boolean flags, including malformed state introduced only before the first byte
- any released matched or unmatched S207 package with missing, non-string or
  noncanonical `releasedAt`; valid draft/blocked omissions remain accepted at shape
  validation but never make a matched unreleased package eligible
- source/evidence anchor resolved globally without exact package/question binding,
  or linked evidence referring to a source anchor outside the matched package
- semantically complete generated solution bypassing S215 through a lower-rung label
- exposed attempt relabeled unseen
- guided override fabricating an empty, placeholder or synthetic attempt
- missing guided tutor state, missing adjacent edge, transition endpoint outside the
  enum, undeclared edge, exposure-commit shortcut or `ATTEMPT` inside guided path
- continued guided help after exposure-commit failure or guided exit after durable-
  schedule failure
- guided exit without a later distinct independent review schedule
- D+1 across a mismatched frozen configuration
- security repair silently preserving incompatible evidence
- D+7 rights missing/blocked/stale/foreign or scoped to another learner/case/use
- D+7 source/effective version missing/stale/mismatched/foreign; partial, superset or
  cross-skill target; same item or same-surface family
- D+7 answer/rubric/validator missing/stale/foreign; unseen snapshot missing, foreign,
  unsealed, reused or created after presentation; any pre-attempt help byte
- D+7 assisted/guided/synthetic/placeholder/unsuccessful/incomplete attempt, replay,
  cache/prefetch/direct-route/multi-tab contamination, or post-success currentness drift
- outer D+7 summary `true` while any trusted conjunct fails
- Practice Golden missing any required GIII routine field
- ts-fsrs declared outside `benchmark_only` or advanced to its future learner-hidden

  separately authorized transition
- pyBKT marked shadow before O2/event sufficiency
- a dependency/model-adapter lifecycle row with a missing, duplicate, unknown,
