## Outcome

The repository-source inventory is complete for the baseline's reachable source/learner-content paths and for explicit no-adapter searches. CPF-1 itself is **not complete**: seven reachable provider, hosting, database-copy, browser and operational settings remain unknown because this Work forbids live service inspection.

The audit confirms 16 data-boundary violations or unsafe implementations. Most importantly:

- `exam_sessions.raw_payload` persists the complete Owner Alpha session, including D1-D4 and full provider output.
- `containsRawContent: false` is present beside raw/source-bearing columns and therefore cannot serve as a proof.
- `/problem-snap/save` converts arbitrary provider/source text into durable learning signals without a value-level D0-D6 classifier.
- database, filesystem fallback, browser storage and provider routes persist or transmit data outside the V12 zero-retention/closed-projection contract.

No application write adapter was found for current learner-source uploads to Supabase Storage/object storage, a durable server queue/DLQ, Redis/KV, embeddings/vector/RAG/training/evaluation corpora, or a session-replay SDK. That negative source finding does not resolve managed platform settings.

## D0-D6 decision boundary

| Class | Meaning | CPF sink rule |
| --- | --- | --- |
| D0 | raw source image/crop/page | zero durable retention |
| D1 | OCR/source expression/question text | zero durable retention |
| D2 | reconstructable derivative/fingerprint | zero durable retention |
| D3 | source-bound full/provider output | client-only, zero durable server retention |
| D4 | learner-authored body | learner-private only after a documented scrub |
| D5 | closed learning evidence | learner-private closed-code projection |
| D6 | bodyless operational metadata | allowed through strict fixed fields |
